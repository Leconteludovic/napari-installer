## Course overview

The napari course covers:

- napari vs ImageJ comparison (advantages, use cases)
- Interface walkthrough: layer controls, viewer controls, dock widgets
- Key plugins: Cellpose, clEsperanto, PhasorPy, napari-animation, chatGPT integration
- Installation: manual (Miniforge/conda) and automatic (Pixi) methods
- How to set voxel size and contrast limits via the Jupyter console
- Plugin installation from the napari hub

**Audience**: biologists and microscopists with no prior Python experience.
